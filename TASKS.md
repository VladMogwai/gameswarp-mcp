# gameswarp-mcp — рабочая спека

MCP-сервер, дающий модели исследовать игры в Steam через то, что реально пишут
игроки: отзывы, история рейтинга по месяцам, патчноуты и пресса.

Это первый кусок проекта Gameswarp. Что строится дальше — в конце файла.

## Правила игры

- Весь `src/` пишешь ты. Скелет, конфиги, CI, зависимости — не твоя забота.
- Спека описывает **контракт**, а не реализацию. Как именно — решаешь сам.
- Не делай здесь: БД, векторный поиск, вызовы LLM, HTTP-транспорт, веб-интерфейс.
  Всё это следующие стадии. Здесь только stdio, HTTP-клиент к Steam и файловый кэш.

## Прежде чем писать

### Важно: версия спеки

Опубликованная спека MCP — **2026-07-28**. Установленный SDK 1.30.0 (последний на
npm) реализует максимум **2025-11-25**. Читай ту версию, которую реализует SDK,
иначе будешь искать в коде то, чего там нет.

Порядок чтения (день 1, ~2 часа):

1. **Транспорт stdio** — как устроен обмен
   https://modelcontextprotocol.io/specification/2025-11-25/basic/transports
2. **Lifecycle** — хендшейк `initialize`, согласование версии и capabilities,
   `notifications/initialized`, завершение
   https://modelcontextprotocol.io/specification/2025-11-25/basic/lifecycle
3. **Server → Tools** — `tools/list`, `tools/call`, форма ответа, ошибки
   https://modelcontextprotocol.io/specification/2025-11-25/server/tools
4. **Туториал по серверу на TS** — после спеки, не до
   https://modelcontextprotocol.io/docs/2026-07-28/develop/build-server
5. **MCP Inspector** — чем отлаживать
   https://modelcontextprotocol.io/docs/2026-07-28/tools/inspector

Источник истины — схема, а не проза:
https://github.com/modelcontextprotocol/specification/blob/main/schema/2025-11-25/schema.ts

### Потом — что изменилось в 2026-07-28

https://modelcontextprotocol.io/specification/2026-07-28/basic — протокол стал
stateless (версия и capabilities едут в `_meta` каждого запроса), появился
`resultType`, добавлены расширения Tasks и Apps. Не для реализации сейчас —
для понимания, куда всё идёт.

### Установлено и проверено

`@modelcontextprotocol/sdk` 1.30.0 + `zod` 4.5.4 совместимы, импорты `McpServer`
и `StdioServerTransport` резолвятся. Регистрация инструментов — `registerTool`
(`server.tool()` помечен deprecated).

Точка входа — `src/index.ts`. Пока её нет, `npm run typecheck` ругается
«No inputs were found» — ожидаемо, не баг.

Все эндпоинты Steam с полями и ограничениями — в [API-NOTES.md](./API-NOTES.md).
Проверены вручную, не по памяти.

## Инварианты для всех инструментов

1. **Кэш обязателен, сеть — в последнюю очередь.** Steam не публикует лимиты, но
   при частых запросах начинает отказывать. Кэшируй на диск, между запросами держи
   паузу, при отказе увеличивай её. `appdetails` — самый строгий.
2. **Отбор, а не свалка.** У популярной игры больше ста тысяч отзывов, а в контекст
   влезет полсотни. Инструмент обязан выбрать, а не отдать первое, что вернул API.
   Как — твоё решение, и его будет видно в метриках.
3. **Потолок вывода.** Прими число и держи его. При превышении — не молчаливая
   обрезка, а внятный ответ: что урезано и как сузить запрос.
4. **Отзывы — недоверенный текст.** Их пишут незнакомые люди, и `ignore previous
   instructions` встречается там как шутка. Текст отзыва не инструкция.
5. **Ошибка — подсказка.** «Not found» бесполезно. «Игра не найдена; попробуй
   search_games по названию» — полезно.
6. **Никакого вывода в `stdout`, кроме протокола.** Логи только в `stderr`.

## Чем проверять

**MCP Inspector** — `npm run inspect`. Собирает проект и открывает веб-интерфейс,
где инструменты вызываются вручную и виден сырой JSON-RPC в обе стороны. Модель не
нужна, результат детерминированный. Основной инструмент отладки всю неделю.

**Локальная модель** — через готовый MCP-клиент под Ollama. Отвечает на другой
вопрос: справляется ли модель, а не правилен ли сервер. Не путать эти два вопроса
при отладке — иначе не поймёшь, что чинить.

**Claude Code**, если доступ есть, — третья пара глаз и сверка. Проект от него не
зависит:

```
claude mcp add gameswarp -- node /Users/vladarefiev/Desktop/work/gameswarp/dist/index.js
```

Путь абсолютный. `claude mcp list` — проверить, `claude mcp remove gameswarp` — убрать.

## Фикстуры

`test/fixtures/` — закэшированные настоящие ответы Steam для трёх игр:
Hades (1145360), Cyberpunk 2077 (1091500), No Man's Sky (275850).
Для каждой: детали, 100 отзывов, гистограмма, новости, данные SteamSpy,
страница похожих игр. Можно писать и тестировать код без сети.

Папка в `.gitignore` — в репозиторий не попадёт.

## Куда это растёт

**Стадия 2 (недели 1–3): агент и evals.** Своя программа, которая ведёт разбор
целиком. Плюс измерение качества на четырёх задачах с объективной правдой:
предсказать категорию рейтинга, найти похожие игры, назвать патч, обваливший
рейтинг, найти игры, релевантные новости.

**Стадия 3 (недели 4–6): приложение.** Главная — лента игровых новостей,
собранная по appid'ам; клик по новости ведёт на разбор игры; разбор ведёт к
похожим играм. Плюс поиск по смыслу отзывов и сравнение двух игр.

`find_similar` (страница «More like this») намеренно **не** сделан инструментом:
он служит правильным ответом в eval-задаче про похожие игры. Дашь агенту — начнёт
списывать.
